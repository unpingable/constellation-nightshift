# Service investigation owner

`tools/nightshift_service_investigation.py` is the bounded, model-free owner for an exact two-profile service investigation. It accepts the versioned authoring handoff, binds the pre-admitted NQ systemd and HTTP watchers, obtains a separate Standing diagnostic mandate and retains exact submission/refusal/reconciliation records. It does not infer authority from the handoff or re-acquire an unrelated obligation.

All programs, store locations, logical execution identity and profile bindings come from a separate operator configuration. Application targets and deployment adapters belong to the caller. The retained Python wire names identify the existing contract, not a component dependency on an application repository.

Run `python3 -m pytest -q tests/test_service_investigation.py` for deterministic subprocess fixtures. This development publication does not establish installed runtime qualification or authorize provider or target contact.
