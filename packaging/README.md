# Constellation Nightshift package

Nightshift owns recurrence and temporal observation. It does not authorize or
execute an effect. Installation supplies inert service/timer units and the
`nightshift` and `nightshift-observation-resolver` executables.

The prepared combined candidate targets Ubuntu 22.04 amd64. Use its source-free
[operator guide](https://github.com/unpingable/unpingable-site/blob/dev/operator-beta/constellation/combined-candidate/README.md) for download verification, exact package installation,
separate enrollment, Workbench, currentness and day-two recovery. It is a neutral
owner-review candidate; BC1 is not tagged or published. Component source alone
does not install the composed product or grant authority.

Inspect `nightshift --version`, `dpkg-query -W constellation-nightshift` and the
candidate runtime checksum manifest. Configure the exact enrolled observation
cycle and resolver in `/etc/nightshift/observation-cycle.env` before enabling
`nightshift-observation-cycle.timer`. A fixture resolver is not production support.

Inspect the timer/service journal and native cycle/status records. Incomplete
support remains incomplete; recurrence never renews evidence or authority. Stop
the timer and service before upgrades/removal and preserve their state.
